Tải ảnh từ Google Drive về điện thoại ✨

Google API key
📖 Hướng dẫn

1. Lấy Google API key (miễn phí)

  1. Mở console.cloud.google.com và đăng nhập tài khoản Google.
  2. Bấm chọn project ở thanh trên cùng → New Project → đặt tên bất kỳ → Create.
  3. Vào trang Google Drive API → bấm Enable (Bật).
  4. Vào APIs & Services → Credentials → Create credentials → API key.
  5. Sao chép key (dạng AIza…) và dán vào ô Google API key ở trên. Trình duyệt sẽ tự nhớ cho lần sau.

🔒 Nên bấm Edit API key để giới hạn: mục API restrictions chỉ chọn Google Drive API, mục Website restrictions thêm tên miền web của bạn (ví dụ https://ten-ban.github.io/*).

2. Chia sẻ thư mục "Bất kỳ ai có đường liên kết"

Trên máy tính (drive.google.com):

  1. Chuột phải vào thư mục → Chia sẻ → Chia sẻ.
  2. Ở mục Quyền truy cập chung, đổi "Bị hạn chế" thành Bất kỳ ai có đường liên kết, vai trò Người xem.
  3. Bấm Sao chép đường liên kết → Xong, rồi dán link vào ô ở trên.

Trên điện thoại (app Google Drive):

  1. Bấm dấu ⋮ cạnh thư mục → Chia sẻ → Quyền truy cập chung (hoặc "Quản lý quyền truy cập").
  2. Đổi "Bị hạn chế" thành Bất kỳ ai có đường liên kết.
  3. Quay lại, bấm ⋮ → Sao chép đường liên kết.

💡 Ảnh nằm trong thư mục con sẽ không hiện, hãy dán link của đúng thư mục chứa ảnh.
