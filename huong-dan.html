Phần 1 · Chia sẻ thư mục ảnh

Làm trong app Google Drive. Mỗi thư mục chỉ cần làm 1 lần.

1

Mở app Google Drive, bấm dấu ⋮ bên cạnh thư mục ảnh

2

Bấm Chia sẻ

Điện thoại cài tiếng Anh: bấm Share.

3

Bấm vào chữ Bị hạn chế

Tiếng Anh: Restricted. Nếu không thấy, bấm Quản lý quyền truy cập (Manage access) trước.

4

Chọn Bất kỳ ai có đường liên kết

Tiếng Anh: Anyone with the link. Sau đó bấm nút quay lại ←.

5

Bấm lại ⋮ rồi chọn Sao chép đường liên kết

Tiếng Anh: Copy link. Link đã được copy, giờ sang Phần 2.

Phần 2 · Tải ảnh về điện thoại

Làm trên trang Mr.MinhDepTrai.

6

Chạm giữ vào ô trắng → bấm Dán → bấm Xem

Ảnh hiện ra sau vài giây.

7

Chạm vào những ảnh muốn lấy. Ảnh được chọn có dấu ✓ xanh

Muốn lấy hết thì bấm Chọn tất cả. Chạm lần nữa để bỏ chọn.

8

Muốn xem ảnh to: bấm 🔍 ở góc ảnh

Bước này không bắt buộc, dùng khi muốn xem rõ ảnh trước khi chọn.

9

Xem ảnh to, vuốt ngang để xem ảnh khác

  • Vuốt sang trái / phải (hoặc bấm ‹ ›) để xem ảnh khác.
  • Chạm 2 lần hoặc dùng 2 ngón để phóng to, chạm 2 lần nữa để thu nhỏ.
  • Bấm Chọn ảnh này để chọn luôn. Bấm ✕ để đóng.
10

Bấm nút xanh Tải về ở dưới cùng

Chờ một chút để máy tải ảnh, nút sẽ hiện "Đang tải…".

11

Bấm Lưu vào điện thoại

12

iPhone: bấm Lưu 2 hình ảnh

Tiếng Anh: Save 2 Images. Ảnh vào app Ảnh (Photos).

12

Android: ảnh tự lưu, mở app Thư viện để xem

Tuỳ máy: Thư viện (Samsung), Bộ sưu tập (Xiaomi, Oppo) hoặc Ảnh (Google Photos). Ảnh nằm trong album Download.

🎉 Xong! Ảnh đã nằm trong điện thoại.

Phần 3 · Tạo API key

Chỉ người cài đặt web làm 1 lần, nên làm trên máy tính. Người dùng bình thường bỏ qua phần này.

1

Mở trang bật Drive API, kiểm tra Project rồi bấm NEXT

Mở trang bật Drive API ↗

① Ô Project phải là project của bạn (ví dụ my-api-key-youtube). Nếu chưa đăng nhập, Google sẽ hỏi đăng nhập trước.

2

Bấm ENABLE

Chờ vài giây. Thấy chữ API enabled hoặc nút MANAGE là xong.

3

Mở trang Credentials, bấm + CREATE CREDENTIALS → API key

Mở trang Credentials ↗
4

Bấm 📋 để copy key

Key có dạng AIza…. Dán tạm vào Ghi chú hoặc Zalo cho khỏi mất, rồi bấm CLOSE. Sau đó bấm vào tên key (ví dụ API key 1) trong danh sách để sang bước 5.

💡 Nếu Google hiện bảng Create API key có sẵn các mục giới hạn, làm luôn bước 5–6 trong bảng đó rồi bấm Create.

5

Khoá key theo web: chọn Websites → + ADD → dán địa chỉ web

③ Dán đúng địa chỉ này (chạm để chọn hết rồi copy):
https://leducminh2310.github.io/*
rồi bấm DONE.
6

Chỉ cho dùng Drive: Restrict key → Google Drive API → SAVE

② Bấm vào ô, gõ drive, tích Google Drive API → OK. Không thấy Google Drive API? Làm lại bước 1–2 để bật API trước.

7

Dán key vào trang Mr.MinhDepTrai

① Bấm Google API key để mở ô. ② Chạm giữ vào ô → Dán. Trình duyệt sẽ nhớ key cho lần sau.

💡 Muốn mọi máy đều không phải nhập: gắn key vào dòng const API_KEY trong file index.html.
