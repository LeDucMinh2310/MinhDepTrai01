Tải ảnh từ Google Drive về điện thoại ✨
📖 Hướng dẫn có hình ảnh từng bước
Google API key
📖 Hướng dẫn

Lấy API key (làm 1 lần)

📖 Xem hướng dẫn có hình ① Bật Google Drive API ↗

Chọn project bất kỳ → Next → Enable.

② Tạo API key ↗

+ Create credentials → API key → copy key (dạng AIza…) → dán vào ô Google API key ở trên.

Chia sẻ thư mục ảnh

Mở Google Drive ↗
  1. Chuột phải vào thư mục (điện thoại: bấm ⋮) → Share.
  2. Mục General access: đổi Restricted thành Anyone with the link.
  3. Bấm Copy link → dán vào ô ở trên → Xem.

💡 Ảnh trong thư mục con sẽ không hiện, hãy dán link của đúng thư mục chứa ảnh.
